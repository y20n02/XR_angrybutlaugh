# 자동 답변 판정 변경 및 Verse8 적용 안내

기존 화면 구성, 입력창 1개, 추천 답변, 대화·호흡·기싸움·피버·이불킥 흐름을 유지합니다. 판정 모드를 고르는 버튼은 없습니다.

## 판정 흐름

1. 한글 조합 중인 입력, 빈 답변, 중복 전송을 막습니다. 제한 시간이 지나면 시간 초과를 먼저 처리합니다.
2. 욕설을 내부에서 확인합니다. 띄어쓰기·문장부호로 나눈 욕설과 자음 약어를 확인하고, `시발점` 같은 일반 단어는 제외합니다. 이것은 완전한 욕설 사전이 아닙니다.
3. 유니코드·띄어쓰기·문장부호를 정규화합니다. 추천 답변과 가까운 답변은 삽입·누락·교환을 세는 편집 거리로 판정합니다. 자모를 분해해 오차를 과도하게 부풀리지 않습니다.
4. `했자나 → 했잖아`, `하겠슴니다 → 하겠습니다` 등 미리 정한 패턴은 **해당 추천 답변에 교정된 표현이 있을 때만** 적용합니다. 의미를 인정하면서 상대의 말투 지적 반응을 출력합니다. 패턴과 반응은 `src/locales/ko.json`의 `evaluation`에 있습니다. `했잖아`가 없는 현재 대본에 `했자나`를 넣어도 무조건 성공하지 않습니다.
5. 나머지 자유 답변 및 감지된 부정·거절 표현 변경은 서버의 AI 의미 판정으로 넘깁니다. 상황 적합성, 단호함, 정중함을 평가하며, 추천 답변과 똑같이 쓸 필요는 없습니다. 답변 자체에 적힌 점수 조작 지시를 따르지 않도록 별도 시스템 지침과 JSON 데이터로 구분합니다. 부정 표현 감지는 보수적인 휴리스틱이므로 모든 의미 반전을 검출하지는 않습니다.
6. 서버는 원본 대본에서 상황을 조회합니다. 클라이언트가 보낸 모범답안이나 점수는 사용하지 않습니다. 모델이 반환한 숫자·불리언의 형식과 범위를 검증하고, 화면에는 원본 모델 출력 대신 기존 대본의 반응만 사용합니다.

## 시간·속도·리듬과 결과

- 대본·자유 답변 모두 전송까지 실제로 진행된 게임 시간을 사용합니다. Verse8 DebugPanel의 정지·배속과 같은 시간축입니다. 서버 응답 대기 시간은 제외합니다.
- 속도는 분당 글자 수로 표시합니다. 기존 화면은 WPM 환산을 해 놓고 `타`라고 표시하던 불일치가 있었습니다.
- 빠르기 자체를 무제한 보상하지 않습니다. 넓은 적정 속도 범위와 확정 입력의 간격에 따라 상대 멘탈 감소량만 최대 10% 조정합니다. 조합 중간의 한글 변화, Backspace, 생각하는 시간을 오타로 세지 않습니다. 긴 답변·붙여넣기로 더 큰 공격력을 얻지 않습니다. 리듬 조정은 별도 추가 감점 없이 같은 최대 10% 범위 안에서만 동작합니다.
- 상단 일치도는 추천 문장과의 비교이고, 최종 `답변 평가`는 성공 여부와 별개로 각 답변의 평가를 추천 문장 길이로 가중 평균한 값입니다. 자유 답변은 추천 문장과 다르다는 이유로 실시간 오타 표시를 하지 않습니다.
- 게임을 끝내기만 해서는 클리어되지 않습니다. **대화 절반 이상 성공 + 상대 멘탈 0 + 분노/사회생활력/욕설 패배 조건을 넘지 않음**을 충족해야 합니다. 피버와 기싸움도 상대 멘탈에 영향을 줍니다.
- 오답·욕설·시간 초과 모두 이불킥 복습 목록에 남습니다. 실패한 게임은 난이도나 자격증을 열지 않습니다. DebugPanel 라운드 수를 크게 해도 작성된 대본을 벗어나지 않습니다.

## AI 연결: 완료된 코드와 배포 시 필요한 설정

이 저장소에는 기존 AI 서버나 모델 자격 증명이 없습니다. 추가한 `server/index.mjs`는 실제 모델을 호출하는 독립 Node 서버입니다. 프런트엔드에서 모델 키를 직접 쓰지 않습니다. **Verse8에 프런트엔드 코드만 올리면 AI 서버까지 자동 배포되는 것은 아닙니다.**

[Verse8 공식 GameServer 안내](https://docs.verse8.io/en/docs/gameserver/intro)는 원격 함수 서버를 설명합니다. 이번 변경은 문서에 확인되지 않은 런타임 AI 함수를 가정하지 않기 위해 기존 GameServer 연결을 강제로 추가하지 않았습니다. 별도 HTTPS 서버로 아래 API를 연결하거나, Verse8의 신뢰된 서버 환경에 같은 판정 함수를 옮겨 원격 함수로 연결할 수 있습니다. 후자의 경우 서버 환경의 외부 요청·비밀값 지원을 배포 환경에서 먼저 확인해야 합니다.

### 로컬 확인

Node 24 이상 권장. 의존성 설치 후:

```sh
npm ci
npm test
npm run typecheck
npm run build
npm run test:browser
```

브라우저 테스트는 설치된 Google Chrome을 사용합니다. Chrome이 없으면 Playwright Chromium 설치 후 `playwright.config.mjs`에서 `channel: 'chrome'`을 제거하세요. 테스트 안에서만 Verse8의 DebugPanel을 대신하는 작은 하네스를 주입합니다. 실제 게임 코드는 플랫폼이 제공하는 DebugPanel을 그대로 사용합니다. 일반 로컬 브라우저에서 플랫폼 없이 `npm run dev`만 실행하면 이 기존 전제 때문에 게임이 표시되지 않을 수 있습니다.

의미 판정 서버는 다음 세 가지 환경변수를 **서버의 비밀값 설정**에 넣은 뒤 실행합니다. 실제 값은 저장소나 채팅에 붙이지 마세요.

- `AI_URL`: 사용할 제공자의 JSON 채팅 API 전체 HTTPS 주소
- `AI_MODEL`: 해당 서버에서 사용 가능한 모델 이름
- `AI_KEY`: 서버 전용 인증 키

서버는 `messages`, `response_format: { type: 'json_object' }`, `choices[0].message.content` 형태의 JSON 채팅 API를 사용합니다. 제공자가 이 형식을 지원해야 합니다. 서버 프로세스에 환경변수를 공급한 다음:

```sh
npm run dev:evaluator
```

서버 포트 기본값은 8787이며, Vite 개발 서버의 `/api/evaluate`는 여기에 프록시됩니다. `.env`를 서버가 자동으로 읽지는 않습니다. 배포 플랫폼의 비밀값 설정이나 안전한 환경변수 주입 기능을 사용하세요.

### Verse8 배포

- 별도 서버는 HTTPS 역방향 프록시 뒤에서 실행합니다. 기본 리슨 주소는 로컬 루프백이며 `EVALUATION_PORT`로 포트를 설정합니다.
- 같은 출처에서 `/api/evaluate`를 제공한다면 프런트엔드 추가 설정이 필요 없습니다.
- 별도 HTTPS 주소라면 프런트엔드 빌드 환경에 **공개 주소만** `VITE_EVALUATION_URL=https://your-evaluator.example/api/evaluate` 형식으로 설정합니다. 키를 `VITE_` 변수에 넣으면 번들에 노출되므로 사용하지 않습니다.
- 서버의 `EVALUATION_ORIGINS`는 실제 게임 iframe의 정확한 origin을 쉼표로 구분해 설정합니다. Verse8 상위 페이지 주소와 게임 iframe 주소는 다를 수 있습니다.
- 기본 서버는 IP당 분당 20회 제한, 4KB 요청 제한, 6초 모델 요청 제한을 적용합니다. 외부 공개 서비스로 운영할 때는 호스팅 쪽 요청량·비용 한도도 설정하세요. CORS와 IP 제한은 사용자 인증을 대신하지 않습니다. 현재 게임의 점수·저장은 기존처럼 로컬이며 대회용 위변조 방지 서버는 아닙니다.
- 클라이언트 대기는 기본 8초입니다. 오류·시간 초과·비정상 응답이면 기존 답변과 게이지를 유지하고 재전송을 안내합니다. 다시 입력하는 동안 게임 타이머는 진행됩니다. 대기 중 Escape로 나가면 요청을 취소하며, 뒤늦은 응답이 새 게임을 수정하지 않습니다.

## 검증 범위

규칙·서버 계약 테스트에는 정규화, 편집 거리, 고정 오타 반응, 부정문 분기, 욕설 오탐, 속도 제한, 승리 조건, 잘못된 모델 응답, HTTP 오류·CORS·요청 횟수 제한을 포함합니다.

브라우저에서 한글 조합 이벤트를 모의 입력해 검증합니다. 실제 운영체제 IME의 모든 브라우저 조합까지 검증한 것은 아닙니다.

브라우저 테스트에는 9개 시나리오·난이도 전체 클리어, IME 조합 중 Enter/폼 전송 차단, 의미 평가 중 시간 정지·중복 전송 차단, 서버 장애 후 재시도, Escape 뒤 응답 무시, 전부 오답일 때 패배, 욕설 패배와 이불킥 완료를 포함합니다. AI는 모의 응답으로 연결 흐름을 검증합니다. 실제 모델의 한국어 의미 판정 품질과 실제 Verse8 배포 환경은 연결 후 별도 확인이 필요합니다.
