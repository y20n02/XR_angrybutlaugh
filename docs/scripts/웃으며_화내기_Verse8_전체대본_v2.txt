〈웃으며 화내기〉 Verse8 상황별 전체 대본

[Verse8 대본 적용 안내]
이 파일은 〈웃으며 화내기〉의 해당 상황/난이도에 사용할 확정 입력용 대본이다.
기존 UI, 타이핑 판정, 게이지, 미니게임, 엔딩 구조는 유지한다.
각 ROUND에서 상대방 대사를 먼저 보여주고, 플레이어 반박 문장을 타이핑 목표 문장으로 제시한다.
플레이어 반박 문장은 원문 그대로 사용하고 한국어 IME 조합 입력을 지원한다.
대화 순서는 상대방 대사 → 반박 문장 제시 → 입력 → 판정 → 반응 → 다음 ROUND이다.
성공/실패에 따른 상대방 반응은 기존 시스템의 분기 로직을 사용한다.
아래에 명시되지 않은 피버타임 문장이나 반응 대사는 이 파일에 포함되어 있지 않다.

플레이어 반박(타이핑 목표): 내가 조사하고 니가 보고하면 내이름은 어디 들어가는데?

ROUND 02

플레이어 반박(타이핑 목표): 우리가 남은 아닌데 그렇다고 니가 나도 아니잖아

ROUND 03
상대방(동기): 아~ 부장님이 아까 내가 준비한 자료 좋다고 하시더라ㅎㅎ 우리 둘이 한 거니까 괜찮지?
플레이어 반박(타이핑 목표): 아 그래? 부장님이 오해하셨네. 내가 직접 정정해 드릴게 ㅎㅎ
